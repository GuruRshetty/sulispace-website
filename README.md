# Sulispace

A simple clothing storefront built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Open the repository’s **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then click **Save**.

## Notes

The shopping bag, checkout button, and email signup are front-end demos. They do not process payments or store email addresses. Product photos and fonts load from external services.
